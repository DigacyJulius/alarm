# 更期鬧鐘 ShiftAlarm

一款為輪班工作而設嘅 Android 鬧鐘 App：讀取你 Google 日曆嘅更期（上班時間＋地點），根據你設定嘅「地點設定檔」規則，自動排每日鬧鐘，連後備鬧鐘（防貪睡）都排好晒。

## 功能

- **讀取 Google 日曆**：透過手機帳號同步嘅日曆（Calendar Provider）讀更期，唔使 API key、唔使額外登入
- **地點設定檔（Profile）**：每個上班地點一個設定檔，各自設定：
  - 配對關鍵字（比對事件嘅「地點」＋「標題」，包含即命中，不分大小寫）
  - 早更／午更／晚更各自嘅起身時間
  - 後備鬧鐘數量（主鬧鐘之後再排 N 粒）
  - 後備鬧鐘之間嘅間隔分鐘數
- **更種自動判斷**：事件開始時間落在邊個時段（預設早更 04:00–12:00、午更 12:00–18:00、晚更 18:00–翌日 04:00，可自訂）
- **防貪睡**：主鬧鐘＋後備鬧鐘係獨立精確鬧鐘（AlarmManager exact alarm），唔怕碌走；撳「解除」會一次過取消成組後備
- **貪睡掣**：自訂貪睡分鐘數
- **一般鬧鐘**：獨立於更期嘅自訂鬧鐘，一次性或每週重複
- **穩定性**：重開機／App 更新後自動重排；每 6 小時背景同步；開 App 即同步
- **響鈴**：全螢幕響鈴頁、鎖屏顯示、震動、系統預設鬧鐘鈴聲、可穿靜音同勿擾

## 雲端 Build（唔使裝任何軟件）

1. 進入本 repo 嘅「Actions」分頁
2. 揀「Build APK」，撳「Run workflow」→「Run workflow」
3. 等 3–5 分鐘，進入嗰次 run（綠剔），在頁底「Artifacts」下載 `ShiftAlarm-APK`
4. 解壓得到 `app-debug.apk`，傳去手機安裝（需允許「安裝未知來源應用」）

## 使用流程

1. 首 次 開 App：允許「日曆」同「通知」權限
2. **設定 → 日曆來源**：揀放更期嘅日曆（唔揀＝全部日曆）
3. **地點設定檔 → 新增**：
   - 地點名稱：例如「中環分店」
   - 關鍵字：例如 `中環, IFC`（逗號分隔；事件地點或標題包含任一關鍵字即命中）
   - 分別設定早／午／晚更嘅起身時間、後備鬧鐘數、後備間隔
     例：早更 05:30 起、後備 2 粒、每 5 分鐘 → 05:30、05:35、05:40 三粒鬧鐘
4. （可選）**設定 → 更時段界線**：調整早／午／晚更嘅時段範圍
5. 照平時用 Google Calendar 入更期：事件要有開始時間；「地點」欄填分店／地點（或者喺標題寫關鍵字都得）
6. 返 App 撳「**立即同步**」，首頁就會列出未來幾日嘅鬧鐘；撳「測試鬧鐘」試機
7. **設定 → 豁免電池優化**（強烈建議）；小米／華為等國產機請再喺系統設定加「自啟動」白名單

## 機制說明

- 同步時，App 會查詢日曆未來 N 日（預設 7 日）嘅事件，逐個做關鍵字匹配 → 命中設定檔 → 按 開始時間定更種 → 產生鬧鐘時間陣列 → 全部用 AlarmManager 精 確排程
- 冇事件嘅日子＝冇鬧鐘，休息日唔使手動處理
- 「解除」會標記成組已解除（48 小時內唔會被同步加返）；「貪睡」會加一粒 N 分鐘後嘅一次性鬧鐘，後備照舊會響
- 多個設定檔同時命中時，用名稱排序第一嗰個

## 已知限制

- 同步時機：開 App、每 6 小時背景同步、重啟手機後。喺電腦改完更期，記得開一次 App 確認
- 鬧鐘鈴聲用系統預設鬧鐘聲，暫時唔可以自訂鈴聲
- 事件必須有開始時間先可以判斷更種

## 專案結構

```
app/src/main/java/com/shiftalarm/app/
├── MainActivity.kt          # 入口、首頁（下一個鬧鐘、未來預覽、同步、測試）
├── data/
│   ├── Models.kt            # 資料模型（設定檔、更種設定、鬧鐘項目）
│   └── Store.kt             # DataStore 持久化
├── calendar/
│   └── CalendarReader.kt    # 讀取 Google 日曆事件（時間、地點）
├── core/
│   ├── RuleEngine.kt        # 規則引擎：關鍵字→設定檔、時間→更種、產生鬧鐘陣列
│   ├── SyncEngine.kt        # 同步排程總指揮
│   ├── AlarmScheduler.kt    # AlarmManager 精確排程
│   ├── AlarmReceiver.kt     # 鬧鐘觸發（全螢幕通知）
│   ├── AlarmRingingActivity.kt  # 響鈴頁（貪睡／解除）
│   ├── BootReceiver.kt      # 重開機重排
│   └── SyncWorker.kt        # 背景
└── ui/
    └── Screens.kt           # 地點設定檔、一般鬧鐘、設定三個頁面
```
